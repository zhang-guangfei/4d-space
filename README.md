# 维度之外 · Beyond 3D — Codex 版

一款在浏览器中探索四维空间的中文第一人称游戏。独立开发分支 `codex/4d-space-edition` 始于 `1ab6188bc451cc8585cb9799e32c87a95e152d15`。你和岑遥同时跌入一处异星文明留下的场。隔着几道门，有人跟你同时抬手。离你最近的那个声音，却来自一片空地。

[第一章《外壳上的迷宫》](https://zhang-guangfei.github.io/4d-space/codex/) · [第二章《折页之间》](https://zhang-guangfei.github.io/4d-space/codex/chapter2/) · [本版操作、画面与剧本评估](docs/codex-echo-field.md) · [长期路线图](docs/codex-review-and-roadmap.md)

## 快速启动

需要 Node.js 20+、Python 3；普通运行/测试无需 npm 下载依赖、API 密钥或后端。Babylon.js 已本地内置。

```sh
bash scripts/cloud-setup.sh
npm run check
npm test
npm run serve:fps
# http://127.0.0.1:8000/
```

教学版：`npm run serve:learning`，打开 `http://127.0.0.1:8001/` 或 `/rooms.html`。云环境端口预览见 [开发与云环境](docs/development.md)。不要用 file:// 直接打开 ES 模块。

## 操作

| 操作 | 第一章上 | 第一章下（零重力） |
|---|---|---|
| 方向键 / 捕获后的鼠标 | 转向 | 本体局部转向，可连续翻转 |
| W/S、A/D | 前后/横移 | 视线前后/本体左右喷气，有惯性 |
| Q / E | 无侧滚 | 头向自己左 / 右侧滚 |
| F | 查看模型、交互 | 查看模型、交互 |
| Tab | 望远镜 | 望远镜 |
| T | 切换鼠标环视和自由指针 | 切换后可点击右侧地图 |
| H | — | 挑战开放后，显示或收起路线答案 |
| Space | 跳跃，持续按住悬浮 | 本体上方喷气 |
| Ctrl | — | 本体下方喷气 |
| Shift | 跑步 | 加速 |
| C | 蹲下 | 不作侧滚 |
| V / 左右鼠标 | V 挥手；捕获后也可用左右键挥动对应的手 | 同左 |
| Esc | 关闭模型返回走廊 / 暂停释放鼠标 | 同左 |

两章打开就可以行动，当前背景和目标直接显示。指针自由时可点仪表，用方向键环视；T 在自由指针和鼠标环视之间切换。

两章共用画质设置。自动档根据连续游玩帧时间调节 3D 画面，桌面显卡以约 60 FPS 为目标，有余量时提高采样密度。原生像素和高清采样可手动选择；设置中显示内部绘制尺寸及游玩帧率。

## 第一章进度

上篇沿门查验三种空间假说，回到 W+ 查看新浮影，解开六向门进入下篇。下篇在八室各取三次回声，回到 W+ 按 R 开始挑战。连续走过八个不同房间后，W+ 会出现镜面球。中途重访同一房间，调查记录仍然保留，可以再试。穿过球体后可直接进入第二章。顶部章节导航也可直接试玩。

下篇的六门罗盘下方有一张固定朝向的八胞体立体展开图。当前位置和登记过的胞用不同标记表示。挑战中可点击「显示路线提示」，沿金线编号找到下一胞，再在六门罗盘里找同名门。刚跨过门槛时仍有机会退回上一个胞。

八室边长 6，直行四胞回路长 24。每室通向六个非对面胞。房间配色固定：W+ 白、W− 黄、X+ 红、X− 橙、Y+ 蓝、Y− 绿、Z+ 紫、Z− 青。左侧维纳斯、右侧大卫的身份跟随胞，不能按屏幕左右永久固定。

## 第二章《折页之间》

用 WASD 行走，鼠标拖动或方向键转向，靠近当下要取、接合或测量的对象时按 F。右侧操作台和第一人称场景共享 W 坐标、旋转角与货栈状态。按 T 捕获鼠标环视，再按 T 释放指针操作仪表。完成小节后按 N 可继续；Esc 暂停。

- 在第一人称画面上向上滚动鼠标滚轮，沿 W 前进一格，向下滚动则退一格。主角的 XYZ 保持原位，四周的物件与可见截面随之变化。也可按 `]` 前进、`[` 后退，或点击高维操作台的方向按钮。
- 在四维货栈中，滚轮操控岑遥的引导车沿 W 移动。B 切换货栈观察基，支持旋转的小节可用 R 转动一格。
- 货栈轨道车按 X、Y、Z、W 四个轴各移动一格；遇箱同向推动，箱后要有净空。Z 通往上甲板。两种观测图按 W 或 Z 分组，撤销与重置在右侧操作台。
- 十小节连续推进。顶部小节菜单可直接重访；刷新后可恢复当前小节的操作进度。通讯音效及所有关键线索均有文字反馈。

`npm run build:codex` 将自包含的游戏与资源写入 `_site_codex/`，可把整个目录放在任意静态子路径，第二章入口为 `chapter2/`。`scripts/codex-e2e.py` 在真实 Chromium 中检查两章并采集画面与时间样本。

## 实现边界

八胞组成超立方体的三维边界，不是四维内部；界面投影、切片、物体本身不能混为一谈。游戏用有限深度 portal 光路裁剪与预分配对象池，不是无限递归光线追踪。八胞动画参数来自参考拟合，并非获取原作者建模工程，也不保证逐像素重合。透明相交面采用中心深度排序，部分角度仍可能错序。

自动几何/NullEngine/合成输入测试不等于真实 GPU 或鼠标验收。本版提供独立的 Chromium WebGL 实测，真机帧率和舒适度仍取决于渲染器与输入设备。
