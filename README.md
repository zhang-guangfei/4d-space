# 维度之外 · Beyond 3D

第一人称四维空间体验游戏、真实物理取证实验、几何教学实验室与创作资料。包含 **第一章（回廊空间站·八胞边界）**、**第二章（四维内部四阶段实验场）** 与 **四维超立方体教学实验室**。

## 快速启动

需要 Node.js 20+、Python 3；普通运行/测试无需 npm 下载依赖、API 密钥或后端。Babylon.js 已本地内置。

```sh
bash scripts/cloud-setup.sh
npm run check
npm test
npm run build:site
npm run serve:site
# 统一总览入口：http://127.0.0.1:8080/
```

也可单独运行第一章/第二章：`npm run serve:fps`（`http://127.0.0.1:8000/` 及 `/chapter2.html`），或教学版：`npm run serve:learning`（`http://127.0.0.1:8001/` 或 `/rooms.html`）。不要用 `file://` 直接打开 ES 模块。

## 第一章操作与物理实验仪器

| 操作 | 第一章上 | 第一章下（零重力） |
|---|---|---|
| 鼠标 | 转向 | 本体局部转向，可连续翻转，无世界竖直锁定 |
| W/S、A/D | 前后/横移 | 视线前后/本体左右喷气，有惯性 |
| Q / E | 无侧滚 | 头向自己左 / 右侧滚 |
| F | 查看模型、交互 | 查看模型、交互 |
| L | 发射测地线激光脉冲（实测 24m 直线闭合与 80.1 ns 光程） | 同左（支持全部六向通道） |
| G | 投掷 0.5g 物理探测球（跨门平行移动） | 投掷零重力牛顿惯性探测球 |
| N | 打开物理取证与空间假说验证台（押注/证伪假说） | 同左（解锁三胞角环 90° 和乐证据） |
| M | 开关空间拓扑与陀螺仪面板 | 同左（八胞全通图 + 90° 和乐读数 + 计时） |
| V | 开关程序化空间站音效 | 同左 |
| Tab | 望远镜 | 望远镜 |
| Space | 跳跃，持续按住悬浮 | 本体上方喷气 |
| Ctrl | — | 本体下方喷气 |
| Shift | 跑步 | 加速 |
| C | 蹲下 | 不作侧滚 |
| 左/右鼠标 | 左/右手挥手（验证 24m 背影自像手性不反转） | 左/右手挥手 |
| Esc | 关闭模型或取证台返回走廊 / 暂停释放鼠标 | 同左 |

Esc 被浏览器释放指针锁后，走廊可用鼠标移动兜底；单击画面恢复锁定。兜底在屏幕边缘会停止，正式体验建议锁定鼠标。Tab 只在游戏操控期间拦截，菜单/表单保留正常焦点行为。

## 章节进度与玩法

- **第一章（回廊空间站）**：上篇利用激光脉冲、探测球与挥手取证，阅读三个空间假说，回到 W+ 查看新出现的八胞体魔方模型并点击“打开舱门”进入下篇。下篇六向零重力漂航，可在三胞角环（如 W+→X+→Y+→W+）实测 90° 雷吉曲率和乐；八室各访问三次后开启无重复八胞路线挑战，完成后进入 W+ 镜面球直达第二章。
- **第二章（四维内部 `(-4, 4)⁴`）**：由浅入深四阶段可玩实验（配同步二维纸片人/书页对照与 4D 投影开关）：① 书页对照与 W 轴穿越；② 封闭三维金库「隔墙取物」（含全 W 封闭超墙反例）；③ 互套双环无碰撞解链 + 四顶点手性钥匙 180° XW 刚性镜像翻转；④ 四维超球切片与宇航员截面观察仪（对比教学三维剖面与真实 XW 倾斜二维交集）。

八室边长 6，直行四胞回路长 24。每室通向六个非对面胞。房间配色固定：W+ 白、W− 黄、X+ 红、X− 橙、Y+ 蓝、Y− 绿、Z+ 紫、Z− 青。左侧维纳斯、右侧大卫的身份跟随胞，不能按屏幕左右永久固定。

## 实现边界

八胞组成超立方体的三维边界，不是四维内部；界面投影、切片、物体本身不能混为一谈。游戏用有限深度 portal 光路裁剪与预分配对象池，不是无限递归光线追踪。八胞动画参数来自参考拟合，并非获取原作者建模工程，也不保证逐像素重合。透明相交面采用中心深度排序，部分角度仍可能错序。

自动几何/NullEngine/合成输入测试不等于真实 GPU 或鼠标验收。云浏览器曾不支持 WebGL，实际设备帧率、透明视觉和舒适度需要真实设备检查。
