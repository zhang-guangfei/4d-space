# 维度之外 · Beyond 3D

纯第一人称四维空间探索游戏，面向非物理专业玩家，以**操作驱动的感官体验**代替枯燥公式讲解。包含 **第一章《回廊空间站》——「外壳上的迷宫」** 与 **第二章《折页之间》——「离开画纸的人」（16 小节五幕主线 + 常驻右侧高维全息操作台）**。

- **线上试玩（第一章）**：<https://zhang-guangfei.github.io/4d-space/>
- **线上试玩（第二章 · 16 小节完整战役）**：<https://zhang-guangfei.github.io/4d-space/chapter2.html>
- **多维度评审打分与长期开发路线图**：[docs/review-and-roadmap.md](docs/review-and-roadmap.md)

## 快速启动

需要 Node.js 20+、Python 3；普通运行/测试无需 npm 下载依赖、API 密钥或后端。Babylon.js 已本地内置。

```sh
bash scripts/cloud-setup.sh
npm run check
npm test
npm run build:site
npm run serve:fps
# 第一章：http://127.0.0.1:8000/
# 第二章：http://127.0.0.1:8000/chapter2.html
```

| `X` / `Z` | — | 第 06 小节（`4×4×2×4` 四维推箱子）：`X` 切换 **`XYZ ⇄ XYW`** 切片视图基底，`Z` 撤销一步 |

## 核心亮点与主线流程

### 第一章《回廊空间站》——「外壳上的迷宫」
- **第一人称六向舱门导航罗盘（`radar.js`）**：彻底抛弃难懂的交叉连线拓扑网，改为以**当前所在房间**为中心、随你的视线与零重力 6-DOF 姿态实时联动的 **`▲ 正前门 / ▼ 身后门 / ◀ 左侧门 / ▶ 右侧门 / ↑ 头顶门 / ↓ 脚下门`** 六向舱门导航仪，单独标出唯一无门直通的 **`◎ 对面盲区胞（需走2步）`**，并在一笔画挑战中直观高亮 **`★ 可通行`** 与 **`✗ 已走过（勿进）`**。
- **上篇（四室回廊）→ 下篇（八室六向全通）**：从 24 米外同侧挥手的自己背影，到零重力六向穿越八间彩色房间并完成一笔画巡航，跃入 `W+` 中央的镜面球进入第二章。

### 第二章《折页之间》——「离开画纸的人」（16 小节五幕主线）
- **第一幕 · 初入折页（01–03）**：`01 隔页的呼救`、`02 折叠断渊`、`03 纪念碑谷：四维旋转天桥`（XW 平面旋转天桥 + 与林夏双人踏板共鸣）。
- **第二幕 · 降维碾压（04–08）**：`04 绝密玻璃牢笼`（六面封死密室高维空降救人）、`05 四维封锁线`（赤红超墙底层缺口）、`06 四维推箱：4×4×2×4 矩阵归位`（跨 `W` 维推箱破除三维墙角死锁 + `XYZ ⇄ XYW` 视图基底互换）、`07 巨环死结`、`08 镜中双生与圣钥`（四维魔镜控制互换翻转手性并拼合双生圣钥）。
- **第三幕 · 真四维巨物（09–12）**：`09 超球星核`（$B^4$ 切面缩放与消隐）、`10 超方圣殿`（斜立超立方体切出四面体 ⇄ 八面体 ⇄ 立方体）、`11 分合浮岛`（四维超环面孤岛融合成桥）、`12 双旋星轮`（正二十四胞体克利福德双旋转）。
- **第四幕 · 三体四维碎片与童话（13–14）**：`13 三体四维碎片：魔戒墓地与全透视战舰`（对话古老遗迹「魔戒」，沿第四维全透视展开三层装甲战舰直接取核）、`14 云天明童话：针眼画师与四维旋转伞`（撑开四维克利福德旋转伞抵御降维打击，追随不随三维距离缩小的「深水王子信标」，把被压进二维雪浪画纸的林夏重新折回三维）。
- **第五幕 · 终幕觉醒（15–16）**：`15 四维急诊：透视内脏`（高维无创透视并在第四维弯曲林夏姿态取出体内三块碎屑）、`16 跃出画纸：方舟之心`（俯瞰第一章八胞外壳并开启五维星门）。

## 实现边界

八胞组成超立方体的三维边界，不是四维内部；界面投影、切片、物体本身严格区分。第一章使用有限深度 portal 光路裁剪与预分配对象池；第二章基于纯数学模块 `chapter2-core.js` 驱动双 Babylon.js 场景（主第一人称场景 + 右侧高维全息操作台）。自动几何/NullEngine/仿真测试覆盖核心拓扑、物理、四维推箱、罗盘方位与全部 16 小节状态机，实际 GPU 帧率与舒适度仍建议在目标设备上实测。
