# 维度之外 · Beyond 3D

第一人称四维空间探索游戏。包含 **第一章《回廊空间站》（八胞边界）** 与 **第二章《折页之间》（四维内部六小节第一人称 + `F` 四维超立方体实验室·上帝视角）**。

线上试玩：<https://zhang-guangfei.github.io/4d-space/>

## 快速启动

需要 Node.js 20+、Python 3；普通运行/测试无需 npm 下载依赖、API 密钥或后端。Babylon.js 已本地内置。

```sh
bash scripts/cloud-setup.sh
npm run check
npm test
npm run serve:fps
# 第一章：http://127.0.0.1:8000/
# 第二章：http://127.0.0.1:8000/chapter2.html
```

## 操作

| 操作 | 第一章（回廊空间站） | 第二章（折页之间 · 四维内部） |
|---|---|---|
| 鼠标 | 环视（下篇零重力可连续翻转） | 第一人称 360° 环视 |
| W/S、A/D | 前后/横移（下篇为视线/侧向喷气） | 第一人称前后/横移（或在 `F` 上帝视角下直接移动宇航员小人） |
| Q / E | 下篇：头向左 / 右侧滚 | **沿第四个方向 W 翻动空间书页**（第四小节回旋环内为四维翻转身体） |
| F | 打开房间内的全息猜想模型 | **打开四维超立方体实验室（上帝视角俯瞰并操控你的宇航员小人）** |
| Space | 跳跃，持续按住悬浮（下篇为上喷） | 跳跃 / 悬浮 |
| Shift | 跑步 / 加速 | 跑步加速 |
| 左/右鼠标 | 左/右手挥手（红/金袖标） | 左/右手挥手（与跨层或密室里的同伴宇航员互动） |
| M / V | 房间方位罗盘 / 音效开关 | 音效开关（`V`），第六小节按 `R` 切换透视/倾斜断面 |
| Esc | 关闭模型返回走廊 / 暂停释放鼠标 | 关闭上帝视角返回第一人称 / 暂停释放鼠标 |

## 主线流程

- **第一章《回廊空间站》**：
  - **上篇（玻璃回廊）**：在看似普通的白色走廊里直行四间房回到原地，发现 24 米外的自己背影以及窗外每过一门旋转 90° 的雕像。查看三个三维空间猜想后，回到起点 `W+` 查看新出现的八胞体模型，打开舱门。
  - **下篇（六向漂航）**：重力解除，六扇门全部开启。熟悉八间房后，从 `W+` 出发完成一次不走回头路的八室巡航，走进 `W+` 中央浮现的镜面球，刺破三维外壳进入第二章。
- **第二章《折页之间》**（全第一人称 3D 体验 + 随时按 `F` 切换上帝视角操控宇航员小人）：
  - **第一小节 · 看不见的同路人**：按 `Q / E` 翻到 `W = +1.8` 金色上页与 `W = −1.8` 蔚蓝下页，与另外两页空间里的同路人汇合，跨过 `W = 0` 的断桥。
  - **第二小节 · 密室里的求救者**：面对六面全部由防爆玻璃封死的密室，翻到 `W = +1.4` 页从高维上方走到密室中央，再降回 `W = 0` 页直接出现在密室内部救出光核。
  - **第三小节 · 解不开的死结**：推着金色巨环翻入另一页 `W` 空间，在毫发无损、不发生任何碰撞的情况下解开两只死死相扣的实心金属圆环。
  - **第四小节 · 镜中人的握手**：走进四维回旋环在第四维翻身 180°，亲眼看着自己身上的红袖标左手与金袖标右手左右互换，变成镜像人与同伴完成同侧握手。
  - **第五小节 · 凭空生长的巨球**：穿行于多层 `W` 空间之间，目睹一颗四维巨球在空气中凭空凝结、膨胀为 4 米巨星、又缩小消散（按 `F` 在上帝视角看清巨球其实静止不动，动的是你的小人）。
  - **第六小节 · 透视自身**：高维视线越过封闭的宇航服外壳看清内部跳动的心脏与血管光路；再观察同伴在第四维微微倾斜时留在当前空间页的发光身体断面。

## 实现边界

八胞组成超立方体的三维边界，不是四维内部；界面投影、切片、物体本身不能混为一谈。游戏用有限深度 portal 光路裁剪与预分配对象池，不是无限递归光线追踪。八胞动画参数来自参考拟合，并非获取原作者建模工程，也不保证逐像素重合。透明相交面采用中心深度排序，部分角度仍可能错序。

自动几何/NullEngine/合成输入测试不等于真实 GPU 或鼠标验收。云浏览器曾不支持 WebGL，实际设备帧率、透明视觉和舒适度需要真实设备检查。
