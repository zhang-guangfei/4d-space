# 《维度之外 · Beyond 3D》物理学合理性验证与真实物理实现报告

## 1. 核心游戏思路的物理学合理性评估

本项目让玩家先在 **四维超立方体的三维边界（八胞空间站）** 中探索、利用物理实验逐一证伪错误假说，再通过 **W+ 镜面球** 离开边界进入 **四维内部 `(-4, 4)⁴`**。从微分几何、拓扑学与理论物理视角看，这一递进架构具有高度的数学严谨性与清晰的物理边界：

### A. 严格成立的几何与物理规律（无需“魔法设定”）

| 现象 / 机制 | 数学与物理原理 | 游戏中的实证实验 |
|---|---|---|
| **局部完全正常、整体非欧闭合** | 超立方体边界 $\partial[-H,H]^4$ 拓扑同胚于三维球面 $S^3$，采用分段平直（piecewise-flat）度量：每个胞内部及穿越门面中心时黎曼曲率为 0。 | 玩家在房间中感受不到拉伸或扭曲；只有大尺度探索才暴露异常连接。 |
| **24 m 直线闭合且无离心力** | 沿 `W+ → X+ → W− → X− → W+` 的中心路线是内禀测地线，展开后完全笔直，不产生三维转弯的离心加速度 $a_c = v^2/R$。 | **激光测地脉冲（`L`）** 与 **惯性探测球（`G`）** 均零反射、零侧偏直行 24.00 m（光程 80.1 ns）后从正后方归来——直接证伪「中央大厅弯道假说」与「球壳赤道假说」。 |
| **同手性 24 m 背影自像** | $S^3$ 是可定向三维流形（$\det = +1$），不同于三维莫比乌斯带或平面镜。绕行闭合光路后不反转左右手性且展现背影。 | 面向前方 24 m 自像按 **左/右键挥手**，红标左手保持同侧——直接证伪「平面镜/跑步机错觉」。 |
| **三胞角环 90° 平行移动和乐（雷吉正曲率）** | $\partial[-H,H]^4$ 的全部正曲率以 $\pi/2$ 亏角（Regge deficit angle）集中在 24 条共享一维棱上。绕任一棱走完三胞闭环（如 `W+ → X+ → Y+ → W+`），无力矩平行移动的局部坐标系必精确旋转 **90°**。 | 零重力下飞完三胞角环，**惯性陀螺仪（`M`）** 实测 $\Delta\theta = 90.0^\circ$——平直三维欧氏空间与三维环面 $T^3$ 恒为 $0^\circ$，构成正曲率四维边界的终极物理铁证。 |
| **隔墙取物的成立条件（分离定理）** | 依据 Jordan–Brouwer 分离定理，三维封闭盒在四维中只是余维 2 的薄壳，无法封闭四维区域，故可从有限 $W$ 之外连续无碰撞绕入；但完整八胞边界或全 $W$ 延展超墙构成封闭三维超曲面，数学上绝对不可绕过。 | 第二章阶段二同时提供 **有限 $W$ 金库（正例）** 与 **全 $W$ 封闭超墙（反例）**，全程执行严格四维包络碰撞检测。 |
| **双环解链与刚性手性翻转** | 一维闭曲线在四维无非平凡链环；在 $SO(4)$ 中绕 $XW$ 平面旋转 $180^\circ$ 将 $(x,y,z,0) \mapsto (-x,y,z,0)$，保持全部四维距离不变（刚体等距变换），却使三维有向体积变号（左手变右手）。 | 第二章阶段三实时校验双环最小 4D 间距 $> 0$，以及手性钥匙六条棱长误差 $0.000\%$、三维有向体积比由 $+1.000 \to 0 \to -1.000$。 |
| **四维超球切片与倾斜三维体交集** | 四维实心球 $x^2+y^2+z^2+(w-w_0)^2 \le R^2$ 与 $w=c$ 相交得半径 $r(c)=\sqrt{R^2-(c-w_0)^2}$ 的三维球；而零 $W$ 厚度的三维刚体绕 $XW$ 倾斜 $\theta$ 后与 $w=c$ 的一般交集为无厚度的**二维截面**（$x_{\text{body}}=c/\sin\theta$）。 | 第二章阶段四并列展示超球切片与“教学三维剖切（方案 A）vs 真实 $XW$ 倾斜二维交集（方案 B）”。 |

### B. 需要显式物理设定的理想化边界（诚实告知玩家）

1. **光线与物质为何被束缚在三维边界上？**
   在无约束的四维欧氏空间 $\mathbb{R}^4$ 中，麦克斯韦电磁波按 $1/r^3$ 衰减且偶数空间维违背强惠更斯原理（光脉冲会产生拖尾余晖）；同时光线在胞交界处会直穿四维体空间而非折入邻胞。因此第一章在物理上对应理论物理中的 **三维膜世界波导束缚模型（Braneworld confinement）**——物质与光子被束缚在边界三维流形中沿内禀测地线传播。
2. **第一章上篇的垂直重力**
   纯几何八胞边界没有天然的“地板”方向。上篇的 $0.5g$（$4.905\text{ m/s}^2$）属于主环甲板的人工重力场；打开舱门进入下篇零重力后，才恢复六个方向完全对称的真实八胞拓扑。
3. **埃伦费斯特定理（Ehrenfest, 1917）与人体存续**
   若万有引力与库仑静电力在四维空间推广为 $1/r^3$，行星轨道与氢原子均不存在稳定束缚态。因此第二章明确将玩家与实验体定义为 **理想三维刚体代理**，并标注教学解剖模型仅为结构观察示意，不宣称真实人体可在四维体空间存活或被无伤切开。
4. **“切片”“投影”与“物体本体”严格区分**
   人类只有二维视网膜。游戏所有界面均严格标明当前显示究竟是 **当前 $W=c$ 三维切片交集**、**4D→3D 投影参考** 还是 **教学剖面示意**，帮助玩家建立准确的几何直觉而非误解。

## 2. 本次新增的真实物理效果与探索闭环

- **第一章物理仪器（`physics-lab.js` + `chapter-enhancements.js`）**：
  - `L` **激光测地脉冲器**：沿真实四维边界流形追踪光线，含玻璃/墙面镜面反射与 24 m 零反射背向归来计时（80.1 ns）。
  - `G` **惯性物理探测球**：上篇服从 $0.5g$ 弹跳与跨门平行移动，下篇服从零重力牛顿第一定律测地飞行，同步渲染在所有可见传送门视角中。

  - **程序化空间音效（`sound.js`）**：零外部文件 Web Audio 合成——舱壁低频共振、步态脚步声、喷气背包/零重力 RCS 冷气推力声、八胞音阶过门谐音、激光与探测球碰撞反馈。
- **第二章四维内部实景（`chapter2-core.js` + `chapter2.js`）**：
