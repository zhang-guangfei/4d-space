# 当前设计：空间站第一章

状态：**当前设计；第一章原型已实现，待真实设备验收**。以下为用户提案的结构化摘要，不是逐字引文，实际实现范围与光学限制见 `../../apps/fps-demo/CHAPTER-1.md`。该方案替代 `archive/` 中旧研究员悬疑方案。

## 上层：有重力的四胞回环

- 空间站走廊基于八胞体边界；先体验前后连通的四胞回环。
- 其余四面为四扇玻璃窗，用于呈现不同方向的联系与自身背部、脚底、头顶等视线效果。
- 始终位于左侧的同一雕像，从不同方位呈现相差 90° 的观察结果。
- 引导玩家比较三种空间猜测：大空间/大厅、跑步机、球面回环。

## 下层：失重八胞探索

- 失重环境开放六个方向的门，在全部八个胞之间探索。
- 最新要求：下层开放后重新开始计数，每个胞进入三次后，提示“尝试从 W＋开始，不重复地走过八个不同房间吧”。此前“每胞十次”要求已取消。
- 挑战须从 W+ 开始一次新的尝试，连续、不重复地走完八个胞。可行路线：`W+ → X+ → Y+ → Z+ → W− → X− → Y− → Z−`。
- 完成第八个不同房间时锁存成功，并立即在 W+ 生成镜面球体；之后返回起点不撤销成功。成功前重复房间只重置路线尝试，不清空模型知识。
- 全息模型属于探索内容，不是最终入口的附加通关条件。
- 上述目标已纳入第一章稳定原型；不适用于保留的旧 v3。
- 本阶段的六向穿门仍是边界上的三维运动，不应误称为已在四维内部自由移动。

## 实现与验收限制

玻璃视像、雕像朝向与内部入口需要明确对应数学模型；若采用示意或简化渲染，必须标注，不能宣称是真实四维光线追踪。第二章不在当前开发请求内。完成度以实际代码、自动测试与用户游玩反馈为准。

## 数学设计注（与用户提案分开）

- 四胞循环的完整路径长度是四个胞沿行进轴的长度之和；旧 v3 每胞 12 单位，因此一周为 48 单位；第一章每胞 8 单位，完整四胞光路一周为 32 单位。并非越过单扇门就回到出发点。
- 看见自身的背部/头顶/脚底需要跟踪具体光线路径与跨胞后的观察基变换；仅凭玻璃窗的存在不能保证看到某个指定自身视像。若做教学示意，画面须说明其简化假设。
- 球面可作为“直行也可能回到起点”的类比，但它与八胞体分片平坦的边界、门连接方式及全部局部几何并不等价，不能用作精确空间模型。
