# 第三轮：交互与界面文档

> **角色**：交互设计师  
> **状态**：待审核  
> **核心目标**：让非专业玩家零学习成本上手四维操作，并确保每一次操作都有明确、即时的反馈。

---

## 一、操作方式规范

| 输入设备 / 按键 | 核心功能 | 适用范围 |
|---|---|---|
| **鼠标移动** | 第一人称 360° 视角环视（第一章下篇支持零重力 6-DOF 姿态） | 全局 |
| **鼠标滚轮 / `Q` `E`** | 沿第四维 `W` 轴平滑切换空间折页（滚轮上/E 为 `W+`，滚轮下/Q 为 `W-`） | 第二章全局（第一章下篇 `Q/E` 为侧滚） |
| **`W` `A` `S` `D`** | 前后左右移动（第 06 关推箱子中为网格步进） | 全局 |
| **`Space` / `Shift`** | 跳跃（或零重力上浮）/ 冲刺 | 全局 |
| **`R`（或左键点击准星目标）** | **核心机关交互**：旋转棱镜、触发开关、翻转手性钥匙、打开全息模型 | 全局 |
| **`F`** | 一键展开 / 收起**右侧高维全息操作台**（上帝视角辅助理解） | 第二章全局 |
| **`Tab` / `M`** | 开关导航罗盘（第一章六向舱门罗盘 / 第二章 W 轴层位标尺） | 全局 |
| **`Z` / `Backspace`** | 撤销上一步（推箱子/逻辑关）/ 快速重置当前关卡 | 全局 |
| **`Esc`** | 暂停、释放鼠标、打开关卡选择与设置 | 全局 |

## 二、核心操作即时反馈设计

| 玩家操作 | 视觉反馈 | 听觉反馈 | 机关动画 | 无效操作反馈 |
|---|---|---|---|---|
| **切换 `W` 折页（滚轮 / `Q` `E`）** | 屏幕边缘微弱的对应层色晕闪过；目标层物体从半透明虚影平滑凝实为实体，非当前层退为清晰虚影；右侧 `W` 标尺游标实时滑动。 | 轻柔的玻璃共鸣滑音（音高随 `W` 值高低变化：星轨低沉、青苍清澈、流金明亮）。 | 空间舱壁光带扫过，虚影线框渐变填充。 | 到达 `W` 轴边界时，标尺两端轻微回弹抖动 + 低沉的“咚”止位音。 |
| **交互机关（按 `R` / 点击）** | 准星靠近可交互物时自动变为高亮菱形并显示单字键位提示 `[R]`；触发瞬间物体爆发一圈白色脉冲环。 | 清脆的机械/晶体咔嗒声。 | 棱镜顺滑旋转 90°（0.25s 缓动），激光束实时重算并延伸；踏板下沉发光。 | 距离过远或物体处于其他 `W` 层时，准星显示灰色虚线框 + 轻柔的“哒哒”空响，并提示“需切换至对应折页”。 |
| **跳跃 / 落脚** | 落地瞬间平台表面泛起一圈柔和的同色涟漪。 | 轻盈的脚步落点声。 | 踩中关键台阶时台阶边缘灯带永久点亮。 | 踩空坠落时无黑屏死亡惩罚，0.4s 柔和白闪瞬间回弹至上一个安全台阶。 |
| **达成阶段目标 / 通关** | 目标物体转为纯净白金色，大厅主光束连通，终点传送门展开。 | 上扬的三和弦晶体共鸣音。 | 传送门几何环展开旋转。 | — |

## 三、UI 元素清单及布局

遵循 **“画面 85% 以上留给空间本身”** 的极简布局原则：

1. **屏幕正中 — 动态准星**：平时为极小半透明圆点；对准可交互物时放大为强调色菱形并附带 `[R]` 图标。
2. **左上角 — 极简目标指示**：仅一行短句（如 `点亮三层信标 (1/3)`），完成时绿色打勾并平滑切换下一条。
3. **左下角 — 快捷操作条（半透明常驻）**：仅展示当前关最核心的 2–3 个键位图标（如 `滚轮 切层` / `R 旋转` / `Z 重开`）。
4. **右侧边缘 — 竖直 `W` 轴层位标尺 + 可折叠高维操作台（`F`）**：用三个色点直观标出 `W = +1.8 / 0.0 / -1.8` 及当前所在层；按 `F` 可展开三维俯视全息图。
5. **右上角 — 三个微缩功能图标**：
   - **重开按钮**（圆形箭头，一键复位本关）
   - **分级提示按钮**（灯泡图标，点击一次给方向提示，点击两次给步骤提示，绝不强行弹出）
   - **关卡选择 / 暂停按钮**（网格图标，支持随时跳关与重玩）

## 四、硬性要求逐条自查

> **硬性要求**：玩家做出任何操作后，必须能立刻判断 **“我做得对不对”** 以及 **“接下来该往哪想”**。

1. **如何立刻判断“我做得对不对”？**
   - **正反馈即刻可见**：点亮信标、踩中台阶、光束接通光井时，**颜色变化（虚影→实体/白金）、灯带连通、上扬音效、左上角计数 `+1`** 四重信号在 0.1 秒内同步触发，绝无延迟。
   - **误操作明确区分**：触碰异层物体时发出“空响”并提示异层虚影状态；踩空立刻无痛回弹至上一安全点；不会让玩家误以为是“卡 Bug”。
2. **如何立刻判断“接下来该往哪想”？**
   - **未完成目标始终有视觉锚点**：未点亮的信标、未接入的接收水晶、下一级台阶都会以**高辨识度半透明虚影**持续可见，视线所及即方向。
   - **因果线视觉化**：光束、跨维光井、连线灯带直接把“机关 A → 影响位置 B”画在三维空间里，玩家顺着光走就能自然推导出下一步。
   - **主动求助兜底**：若玩家停滞超过 30 秒，右上角提示灯泡仅轻微呼吸闪烁（不打断），点击即可获得精准的“下一步思考方向”。
