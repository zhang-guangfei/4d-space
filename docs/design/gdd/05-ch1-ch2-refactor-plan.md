## Phase 1：公共系统与第 14 关「发丝裂缝」垂直切片（当前执行）

- [ ] **滚轮唯一控制第四维**：
  - 行走状态下：鼠标滚轮 = 自身沿 `W` 轴平移（切换/滑动切片层）。
  - 抓取状态下（按 `E` 抓住可旋转四维物体进入第三人称操作舞台）：鼠标拖拽 = 三维旋转；鼠标滚轮 = 绕关卡预设平面发生四维旋转（如 `XW` 旋转，即绕 `YZ` 面旋转）。
- [ ] **键位统一映射**：
  - 第二章交互键由旧版 `R` 统一改为 `E`（与主流第一人称解谜一致；第一章失重滚转保留 `Q/E` 或在靠近交互点时优先触发交互提示）。
  - 视图切换键由旧版 `X` 统一改为 `Tab`（在“投影视图（示意）”与“侧面视图（`YZW`）/ 当前切片视图（`W=0`）”之间切换）。
  - 提示键统一为 `H`；重开当前关统一为 `R`。

### 1.2 「奇观 → 把玩 → 运用」去打卡化 HUD 与三级提示（D5）
- [ ] **移除开场打卡任务清单**：进入关卡不再直接弹出步骤式做题清单，让玩家先看奇观、自由把玩。
- [ ] **分级口头提示系统（45 秒 / `H` 键）**：
  - 玩家在同一阶段停滞 45 秒后，右上角出现柔和呼吸提示（“按 `H` 听取林夏/墓地的观察”）。
  - 连续按 `H` 依次给出：**1 级（现象提醒）→ 2 级（方向提示）→ 3 级（明确解法）**。

### 1.3 垂直切片关：第 14 关「发丝裂缝」（想法库 #14 · 四维旋转让大球过窄缝）
- [ ] **几何与碰撞核心（`chapter2-core.js`）**：
  - 实现 4D 球盘/扁球体绕 `YZ` 平面（即 `XW` 旋转角 $\theta$）的精确三维截面与投影计算：
    - 物体本征尺寸：$X, Y, Z$ 半径均为 $R = 1.0\text{ m}$（直径 $2\text{ m}$），$W$ 方向厚度半轴为 $\varepsilon = 0.04\text{ m}$（总厚 $0.08\text{ m}$）。
    - 绕 `YZ` 面旋转角 $\theta$ 后，在 `W=0` 切片（或沿 $X$ 方向的最大跨度）上的 $X$ 半宽为：
      $$x_{\max}(\theta) = \sqrt{R^2\cos^2\theta + \varepsilon^2\sin^2\theta}$$
    - 窄缝墙体在所有 $W$ 上都存在（不可靠切层绕过），缝宽 $d = 0.12\text{ m}$（半宽 $0.06\text{ m}$）。
    - 当 $\theta \approx 90^\circ$（允许容差 $|\theta - 90^\circ| \le 4^\circ$）时，$x_{\max} \le 0.06\text{ m}$，圆球立成“薄刃”滑过发丝窄缝，抵达对面基座后再转回 $\theta = 0^\circ$ 恢复圆球。
- [ ] **双视图诚实标注（`chapter2.js`）**：
  - 默认主舞台显示 `W=0` 切片 + 半透明四维投影轮廓（角标注明：`当前切片 W=0 · 外框为四维投影示意`）。
  - 按 `Tab` 切换到 `XZW` / `YZW` 侧面视图，玩家能直观看到“它从未被压扁，只是转到了 $W$ 方向”。
- [ ] **自动化测试（`chapter2-tests.mjs`）**：
  - 校验 $\theta = 0^\circ$ 时 $x_{\max} = 1.0\text{ m}$ 被窄缝阻挡；
  - 校验单纯改变 $W$ 无法绕过全 $W$ 墙体；
  - 校验 $\theta = 90^\circ$ 时 $x_{\max} = 0.04\text{ m} < 0.06\text{ m}$ 可顺利通过窄缝并完成关卡。
