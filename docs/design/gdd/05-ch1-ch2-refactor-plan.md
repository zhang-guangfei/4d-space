# 第一、二章优化重构开发计划（基于 GDD 01–04）

> **说明**：本清单将 `01`–`04` 四份设计文档中的核心规范，映射为《维度之外》现有代码（`apps/fps-demo/dist/`）的具体优化与重构任务。  
> **执行时机**：等待您审核并确认 `01`–`04` 设计文档后，立即按优先级逐项开发并通过自动化测试验收。

---

## 一、叙事与氛围落地（对应 `01-narrative-and-atmosphere.md`）
- [ ] **去弹窗化字幕**：清理第一章与第二章中过长或打断操作的说明文本，统一改为底部单行低饱和度极简字幕（≤15字，3秒自动淡出），完整解说折叠进可随时按需打开的“档案/提示”面板。
- [ ] **过关氛围反馈**：强化过关瞬间的大厅光带蔓延与传送门白金光环动画。

## 二、关卡体验与引导优化（对应 `02-level-design.md`）
- [ ] **第二章第 1–3 关体验精修**：
  - 第 1 关（隔页的呼救）：强化 3 座异色信标塔的虚影→实体过渡与脉冲光柱反馈。
  - 第 2 关（六阶跨维天梯）：确保 6 级台阶始终保持高可读性虚影，坠落时实现 0.4s 柔和白闪无痛回弹至上一安全台阶。
  - 第 3 关（折页棱镜）：强化跨维光井（W-Well）的上下层光束传导视觉连线，让“导光成功”一眼可见。
- [ ] **补全其余关卡设计表**：审核确认 1–3 关模板后，补齐第一章上下篇及第二章第 4–8 关的标准设计表。

## 三、交互与界面重构（对应 `03-interaction-and-ui.md`）
- [ ] **动态准星系统**：平时极小圆点，对准可交互物变为强调色菱形 + `[R]` 提示；对准异层物体显示灰色虚线框 + “需切换至对应折页”轻提示。
- [ ] **极简 HUD 重排**：
  - 左上角：单行目标计数（完成即打勾切换）。
  - 左下角：当前关最核心 2–3 个键位微缩提示。
  - 右上角：重开按钮、分级提示按钮（30 秒停滞轻呼吸提醒）、关卡选择按钮。
  - 右侧边缘：竖直 `W` 轴三色层位标尺（支持 `F` 展开/收起高维操作台）。
- [ ] **四重即时反馈补齐**：为切层、交互、无效操作、落脚、通关补齐对应音效（`sound.js`）与视觉涟漪/脉冲反馈。

## 四、视觉与美术统一（对应 `04-visual-and-art-direction.md`）
- [ ] **严格执行色彩与噪音分离**：审计 `chapter.js`、`chapter2.js`、`chapter.css`、`chapter2.css`，确保背景墙体/立柱严格使用低饱和度主色与辅助色，三大强调色（`#4DE6D3` / `#F7C346` / `#58A6FF`）与白金色 `#FFF6D6` **仅用于可交互物体与 W 层标识**。
- [ ] **字体与排版统一**：统一 HUD 使用现代无衬线字体 + 等宽数字显示坐标与计数。
