## 二、如何与 AI Agent 高效协作？（四步循环）

1. **分角色出稿 + `/grill-me` 逐题拍板**  
   AI 先梳理创意库并按模块出稿，通过每次单选提问（附推荐项）与项目负责人对齐核心决策（D1–D13）。
2. **老板式审核与取舍（你只做选择题和否决权）**  
   你不需要会写专业术语，只需回答三类问题：
   - **“这个我玩起来会不会懵？”**（否决过度复杂的规则）
   - **“这个感觉对不对味？”**（锁定基调与视觉风格）
   - **“先做 A 还是先砍掉 B？”**（控制中型项目的范围，避免无限膨胀）
3. **文档即契约（Doc-Driven Development）**  
   总设计文档 [00-master-gdd.md](00-master-gdd.md) 审核通过后，立刻转化为 [05-ch1-ch2-refactor-plan.md](05-ch1-ch2-refactor-plan.md) 中的具体代码改造项，AI 严格按文档改代码、跑自动化测试，不擅自加戏。
4. **垂直切片先行 → 全量铺开**  
   先落地公共系统与 1 个代表性垂直切片关（第 14 关「发丝裂缝」），确认手感后再按 1→18 顺序铺开。
