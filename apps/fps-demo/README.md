# 四胞回环 FPS 稳定基线 v3

这是空间站第一章开发前的稳定四胞回环原型，不是完整八胞游戏。主 README 提供统一运行与状态说明。

- 鼠标转向、WASD 行走、Esc 暂停；点击进入请求指针锁定。
- `physics.js`：`W+ → X+ → W− → X−` 回环，单胞长 12，周期 48；保留越界余量和方向，圆形碰撞体/分步移动/沿墙滑动。
- `look.js`：唯一视角状态，每帧只应用一次；丢弃首次锁定包、非有限值和异常大包；解锁/失焦/重置清空增量，不积压回放。
- 正常快速多包输入不受逐帧限速或平滑影响。此方案为镜头修复候选，真实鼠标体验仍需用户验证。
- Babylon.js 9.32.1 本地内置，Apache-2.0 许可随附；运行无第三方网络依赖。

在本目录运行 `node tests.mjs`、`node camera-engine-tests.mjs`、`node smoke.mjs`。测试覆盖数学/合成事件/真实 NullEngine，不覆盖 GPU 光栅化与物理鼠标输入。
