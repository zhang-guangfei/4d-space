# 八胞体 GIF：建模与运动参数反推

## 结论

本次重新从生成几何和角点轨迹反推，不把视频倒放或逐帧贴图当作模型。得到一个可直接计算任意时刻的新模型：16 个四维顶点、32 条边、一个 XW 平面的匀速旋转、四维透视投影，再经过固定三维透视相机。相机本身不绕行。

这是与参考运动较接近的参数估计，尚非“完全重合”，也不是恢复了作者原始 Maya 参数。材质高光没有作为几何参数。

## 生成规则

1. 顶点为 (x,y,z,w)，四个坐标各取 ±1；只相差一个坐标的顶点相连，得到32条边。
2. 采用 Y 竖直的坐标约定。旋转：x′=x cosθ−w sinθ，w′=x sinθ+w cosθ；y、z不变。固定平面为 YZ。
3. θ(t)=0.4674989068t 弧度。没有缓入缓出，没有镜头旋转。反向只需把θ取负。
4. 四维投影：p₃=(d₄−1)/(d₄−w′) × (x′,y,z)。这个归一化使初始外立方体半边长为1。
5. 固定三维透视相机再将 p₃ 投影到256×256画面；计算代码见 model.mjs。

## 建议参数

| 参数 | 估计值 |
|---|---:|
| 四维顶点坐标 | 各轴 ±1 |
| 四维透视距离 d₄ | 3.0544 |
| 三维相机距离 | 5.5917 |
| 相机方位角 | 31.723° |
| 相机仰角 | 19.476° |
| 画面滚转 | −1.764° |
| 焦距（256像素画幅） | 345.702 像素 |
| 主点 | (125.505,127.131) 像素 |
| 初始相位 | 0，模90° |
| 每帧间隔 | 70毫秒 |
| 每帧角位移 | 1.875° |
| 角速度 | 26.7857°/秒 |

原 GIF 的48帧、3.36秒只对应90°旋转。由于无编号超立方体的对称性，90°后的线框集合已与起点一致，因此画面可以循环；若追踪同一顶点的身份，完整360°需要13.44秒。不能把GIF一轮误判为完整360°。

## 拟合与独立验证

从参考48帧的可见杆轴截面中，提取6902条局部边线位置观测；利用同一个顶点相连的2至4条可见边求交，得到519个带拓扑编号的角点观测。它们是图像测量值，不是来自作者工程。

用于参数拟合的训练角点396个；预先留出的12帧共123个角点未参与该次参数优化。留出帧编号为2、6、10、14、18、22、26、30、34、38、42、46。

| 模型 | 留出角点坐标RMSE |
|---|---:|
| 四维透视＋三维透视，固定匀速与初始相位 | 2.682像素 |
| 两次透视，额外放开相位及转速 | 2.667像素 |
| 三维改为正交 | 6.502像素 |
| 四维改为正交 | 16.588像素 |
| 两次都改为正交 | 17.035像素 |

额外放开相位和转速的收益很小，因此采用与循环对称性一致的固定匀速模型。建议模型的留出角点二维距离中位数为2.806像素。误差是256×256原始画幅下测得；放大显示会同比放大偏差。

坐标RMSE是对u/v两维残差计算，不能冒充完整二维距离，也不是整图像素相等。可见圆柱厚度、遮挡、反光会使图像杆轴测量偏离真实几何轴。角点观测也依赖拓扑对应假设，因此这是条件验证，不是独立的工程真值。

## 可识别性与不确定性

- 绝对米制大小无法由单目GIF得出，这里主动固定四维半边长1及初始外立方体半边长1。
- 坐标轴名称、符号及90°对称性带来的顶点重新编号存在等价解；XW是本文件选定的清晰约定。
- 保持相同最终投影的某些尺度/焦距组合是等价的；应使用整套参数及明确归一化，不能从中抽一个数当作作者原值。
- 按训练帧重采样24次，参数统计范围见 uncertainty.json。它不包含反光、遮挡和模型失配造成的系统误差，所以不能作为作者真实参数的严格置信区间。
- 管柱半径、材质和高光属于另一个渲染层，本模型的几何反推没有以它们代替角点运动。
- 这里的“原方向”指与参考观测相同的最小连续旋转解释；为先验证生成规律，本模型没有先做逆向、没有人物和雕像。

## 运行与复现

model.mjs 不依赖第三方库。调用 frame(n*0.070) 可得到第n帧的四维坐标 p4、三维投影 p3、屏幕坐标 p2 和边表。传入 {reverse:true} 可将角速度反号。将 p3 与32条边交给3D引擎即可生成真正可变视角的模型，而不是视频纹理。

parameters.json 保存完整精度；corner-trajectories.csv 是观测角点与四维顶点编号；projected-corners.json 是模型预测；model-comparison.json 和 uncertainty.json 是验证结果。fit scripts 需要 Python、NumPy、SciPy、Pillow，脚本原工作目录路径需按解压位置调整。

当前未修改或发布游戏。
